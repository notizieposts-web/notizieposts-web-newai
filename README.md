# Radar AI

Newsletter personale sull'intelligenza artificiale, preparata con Claude (Anthropic).

- `index.html`: archivio di tutte le edizioni
- `edizioni/NN.html`: le singole edizioni interattive
- `tools/RUNBOOK.md`: la procedura completa per preparare e pubblicare un'edizione

Pubblicata con GitHub Pages.

## Palette: "Verde Deloitte"

Scelta il 12 novembre 2026. Il documento di riferimento, con tutti i colori, le misure di contrasto e le fonti ufficiali, è [`docs/palette.md`](docs/palette.md). Stato: applicata a tutto il sito (l'email ha ancora i suoi colori).

- **Base neutra grafite**: fondo `#F6F6F5` e testo `#1C1D1F` in chiaro; fondo `#121212` e testo `#EDEDED` in scuro.
- **Pulsante principale**: verde scuro `#3F7A12` con testo bianco, identico nei due temi (5,24:1 sul testo, WCAG 2.2 AA).
- **Accento**: verde `#86BC24` con testo nero, solo per dettagli brevi in grassetto (serie di giorni, avanzamento).
- **Stati**: giusto verde con ✓, attenzione ambra, sbagliato rosso con ✕; mai solo il colore.
- **Tema scuro**: cambiano solo fondi e testi, non i pulsanti.
- Del marchio Deloitte usiamo solo il colore: niente logo, punto verde o caratteri tipografici.
- Accessibilità WCAG 2.2 AA in entrambi i temi, verificata con `tools/audit3.py`.
